# ECHOSPHERE 2.0 — Official Live Concert Landing & Pass Booking

> **A premium, cinematic, scroll-driven live music experience engineered for Srinivas University Institute of Engineering and Technology (SUIET), hosted by WebFlow Club × Rotaract Club.**

---

## 🌟 Overview & Highlights

- **Scroll-Driven 3D Canvas Scrub**: Preloaded dual-sequence (16:9 full-desktop and 9:16 mobile slice) canvas animation seamlessly synchronized to Lenis smooth scroll and GSAP ScrollTrigger.
- **Dynamic Live Concert Audio**: High-energy concert background beat with interactive equalizer toggle in the navigation bar and smooth auto-unlock.
- **Pass Registration Suite**:
  - Live scarcity meter (`196/200 Booked • Only 4 left at this rate`).
  - Interactive ticket quantity stepper (`[-] 1 [+]`) with real-time recalculation (`₹349` Early Bird, `₹499` regular, savings pill).
  - Attendee validation with simulated Cashfree Gateway checkout.
  - Golden entrance pass generation featuring instant offline matrix QR code and live pass verification.
- **Zero Framework Overhead**: Ultra-fast vanilla HTML5, CSS3 modern variables, and JavaScript with CDN GSAP, ScrollTrigger, and Lenis.

## 🚀 Local Development

1. Clone or download the repository:
   ```bash
   git clone https://github.com/Farhan130612/echosphere-2.0.git
   cd echosphere-2.0
   ```

2. Start the local server:
   ```bash
   node server.js
   ```
   Or double-click `start.bat`.

3. Open in your browser:
   - **Desktop**: [http://localhost:8080/](http://localhost:8080/)
   - **Mobile (LAN)**: [http://<your-local-ip>:8080/](http://localhost:8080/)

---

## 🌐 Deployment to Vercel

This repository is pre-configured for static deployment on Vercel:

1. Import the repository in [Vercel Dashboard](https://vercel.com/new).
2. Framework Preset: **Other** (Root directory: `./`).
3. Click **Deploy**.
